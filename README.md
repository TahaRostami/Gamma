# γ: Computational Queen Domination

Research artifacts for the **queen domination problem**, organized across
separate branches.

---

### [`sat-solving`](../../tree/sat-solving)
#### Queen Domination by SAT Solving

SAT encoding and computational artifacts accompanying
[*Queen Domination by SAT Solving* (v1)](https://arxiv.org/abs/2508.11945v1),
including Hilbert-curve literal ordering, symmetry breaking, and enumeration
of minimum dominating sets.

### [`gamma-plus`](../../tree/gamma-plus)
#### Queen Domination by SAT Solving — improved framework

Improved implementation based on **line variables**, accompanying
[*Queen Domination by SAT Solving* (v2)](https://arxiv.org/abs/2508.11945v2),
with an improved SAT encoding and parallel solve-and-verify pipeline.

### [`upper-bound`](../../tree/upper-bound)
#### Computational constructions for improved upper bounds

Computational artifacts for large queen-domination constructions, including
certificates and independent verification tools.
